사진 정리함 개인정보처리방침

시행일: 2026-09-30

1. 기본 원칙

사진 정리함(이하 "앱")은 사진·동영상 분석 기능을 원칙적으로 기기 안에서만(온디바이스) 처리합니다. 사진·동영상 원본은 어떤 경우에도 서버로 전송하지 않습니다.

2. 수집하는 정보와 처리 목적

항목목적전송 여부
사진 메타데이터(촬영일시, 파일 크기, 위치 좌표)타임라인·중복/유사 사진 탐지·용량 분석을 위해 기기 내부 데이터베이스에만 저장전송 안 함
지각적 해시(pHash), 흐림도중복·유사·흐릿한 사진 탐지전송 안 함
OCR 인식 텍스트스크린샷·기프티콘 자동 분류전송 안 함
이미지 라벨사진 태그 검색전송 안 함
얼굴 특징 벡터(생체정보, 3항 참조)인물별 사진 그룹핑전송 안 함
구매 내역RevenueCat을 통한 구독 관리 (앱 계정과 무관한 익명 ID)RevenueCat으로 전송

3. 생체정보(얼굴 인식 데이터) 처리에 관한 사항

"인물" 기능을 사용하면 사진 속 얼굴에서 192차원 특징 벡터를 추출해 기기 내부 데이터베이스에 저장합니다. 이 벡터는 개인을 식별할 수 있는 생체인식정보에 해당하며, 온디바이스에서만 처리되고 외부로 전송되지 않습니다.

보관 기간: 사용자가 삭제하거나 앱을 삭제할 때까지.
삭제 방법: 설정 → "얼굴 데이터 전체 삭제"에서 전체 삭제, 또는 인물 상세 화면에서 특정 인물만 개별 삭제할 수 있습니다.
동의: "인물" 기능을 처음 열 때 별도 동의 화면에서 명시적으로 동의를 받으며, 동의하지 않아도 다른 기능은 그대로 이용할 수 있습니다. 동의를 철회하려면 설정 → "얼굴 데이터 전체 삭제"를 이용하세요.

4. 위치정보 처리에 관한 사항

설정에서 "타임라인에 지명 표시"를 켠 경우에만, 사진 좌표를 약 2km 격자 단위로 뭉갠 좌표를 기기 OS의 지오코딩 서비스(Android: Google, iOS: Apple)로 전송해 지명을 조회합니다. 정확한 원본 좌표는 전송하지 않으며, 이 기능은 기본값이 꺼짐 상태입니다. 언제든 설정에서 끌 수 있습니다.

5. 제3자 제공 및 처리 위탁

  • RevenueCat — 구독 결제 처리 (익명 App User ID만 사용, 계정 연동 없음) — revenuecat.com/privacy
  • Google AdMob — 리워드 광고 게재 (iOS는 추적 허용 동의 후에만 맞춤 광고) — policies.google.com/privacy
  • Android/iOS 지오코딩 서비스 — 4항의 지명 표시 기능에 한함

위 사업자 외에 개인정보를 제공하지 않습니다.

6. 이용자 권리

이용자는 언제든 다음을 수행할 수 있습니다.

  • 얼굴 인식 데이터 전체/개별 삭제 (설정 → 얼굴 데이터 전체 삭제, 또는 인물 상세 화면)
  • 위치 정보 전송 기능 끄기 (설정 → 타임라인에 지명 표시)
  • 잠금 보관함 데이터 삭제 (보관함에서 개별 삭제)
  • 앱 삭제 시 기기 내 모든 데이터 자동 삭제
